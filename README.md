# NEXUS — موقعك الذكي الشخصي (مجاني 100%)

موقع دردشة ذكاء اصطناعي كامل، يفهم أوامرك، يكتب لك كود حقيقي قابل للتشغيل، ويبث الردود لحظة بلحظة مثل أي مساعد ذكي احترافي. مبني بالكامل على أدوات مجانية:

- **الواجهة**: HTML/CSS/JS خام (بدون أي إطار عمل ثقيل)
- **العقل**: نموذج Llama 3.3 70B عبر **Groq** (استضافة مجانية سريعة جدًا)
- **الاستضافة**: **Vercel** (خطة مجانية دائمة)

---

## أولًا: خذ مفتاح API مجاني من Groq

1. افتح: https://console.groq.com
2. سجّل دخول (بجيميلك مثلاً) — مجاني بالكامل، بدون بطاقة ائتمان.
3. من القائمة الجانبية اختر **API Keys** ثم **Create API Key**.
4. انسخ المفتاح (يبدأ بـ `gsk_...`) واحتفظ فيه — رح تحتاجه بالخطوة الجاية.

> ليش Groq وليش Llama 3.3 70B؟ لأنه مجاني، سريع جدًا (يبث الكلام بسرعة خيالية)، وقوي بالبرمجة والشرح. تكدر تبدل الموديل بأي وكت بالسطر `model:` بملف `api/chat.js`.

---

## ثانيًا: شغّل الموقع على جهازك (اختياري لتجربته محليًا)

يتطلب تثبيت Node.js (نسخة 18 فأعلى) من https://nodejs.org

```bash
cd ai-site
npm install -g vercel        # أداة Vercel لمرة وحدة بس
cp .env.example .env         # انسخ ملف البيئة
```

افتح ملف `.env` وحط مفتاحك:
```
GROQ_API_KEY=gsk_مفتاحك_هنا
```

بعدين شغّل:
```bash
vercel dev
```

افتح المتصفح على الرابط اللي يطلعلك (عادةً `http://localhost:3000`) وجرب الدردشة.

## ثالثًا: انشر الموقع مجانًا على الإنترنت (خطوة بخطوة)

### 1) ارفع المشروع على GitHub
- سوّي حساب مجاني: https://github.com/join
- سوّي مستودع (Repository) جديد فاضي، وسميه مثلاً `nexus-ai`
- من مجلد المشروع نفّذ:
```bash
git init
git add .
git commit -m "أول نسخة من موقعي الذكي"
git branch -M main
git remote add origin https://github.com/USERNAME/nexus-ai.git
git push -u origin main
```
(بدّل `USERNAME` باسم حسابك)

### 2) اربطه بـ Vercel
- سوّي حساب مجاني: https://vercel.com/signup (سجّل دخول بحساب GitHub مباشرة، أسهل)
- بالداشبورد اضغط **Add New → Project**
- اختار المستودع `nexus-ai` اللي رفعته
- قبل الضغط على Deploy، افتح قسم **Environment Variables** وضيف:
  - **Key**: `GROQ_API_KEY`
  - **Value**: مفتاحك من Groq (`gsk_...`)
- اضغط **Deploy**

بعد نص دقيقة رح يطلعلك رابط مباشر مثل:
```
https://nexus-ai-yourname.vercel.app
```

هذا هو موقعك — شغّال، مجاني بالكامل، ومتاح من أي جهاز أو موبايل بالعالم.

## كيف أخليه "يحجي وياي تمام" ويصير أذكى وأقرب لشخصيتي؟

كل شخصية NEXUS متحكم فيها من سطر وحد بملف `public/index.html`، داخل متغير `history` بأول السطر:

```js
let history = [
  { role: 'system', content: 'أنت "NEXUS"، مساعد ذكاء اصطناعي شخصي...' }
];
```

عدّل هذا النص بأي أسلوب تريده: خليه يحجي بلهجتك، يتخصص ببرمجة معينة، يكون مرح أو جاد، يتذكر أسلوبك بالكتابة... هذا النص هو "شخصية" الموقع بالكامل، وبيدك أنت تتحكم فيه 100% بدون أي وسيط.

## هل هو "بدون قيود" فعلاً؟

خلّيني أكون صريح وياك بنقطة مهمة:

- **ما راح يوكف نص السالفة أو يقطع الجواب تعسفيًا** — لأنه مبني بالبث المباشر (streaming) وبـ `max_tokens: 4096`، يعني يعطيك جواب كامل وطويل بدون قطع.
- **يفهم البرمجة، يكتب كود كامل، ويشتغل بحرية بأي موضوع تقني أو إبداعي** بدون رقابة إضافية مني أنا.
- لكن أي نموذج ذكاء اصطناعي — حتى المستضاف عند Groq — عنده حد أدنى من ضوابط الأمان الأساسية (مثل رفض المحتوى الخطير فعلاً: أسلحة، إيذاء أطفال، إلخ). هذا مو شي أكدر أو يصح أزيله، وأي أداة تدّعي إزالته بالكامل غالبًا تكون غير موثوقة أو غير آمنة للاستخدام.

يعني: حصلت على موقع ذكي، سريع، حر بالتعامل والبرمجة والإبداع، وتحت سيطرتك الكاملة من ناحية الشخصية والتوجيه — وهذا أقصى واقعي ومسؤول لتحقيق اللي تريده.

## أفكار للتوسعة لاحقًا

- إضافة ذاكرة دائمة (قاعدة بيانات مجانية مثل Supabase) حتى يتذكر محادثاتك بين الجلسات.
- ربط الموقع بأدوات فعلية (بحث بالإنترنت، تنفيذ كود Python) عبر LangChain.
- تسجيل دخول للمستخدمين حتى يصير كل شخص عنده مساعده الخاص.

إذا تريد أي وحدة من هالأفكار مبنية وياك فعليًا، گلّي وأبنيها وياك خطوة بخطوة.
