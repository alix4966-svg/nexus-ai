# NEXUS — نسخة محدّثة بواجهة تشبه Claude

هاي نسخة معدّلة من موقعك، بنفس البنية (Vercel + Groq)، بس بواجهة وخصائص جديدة حسب طلبك.

## شنو تغيّر بالضبط؟

### 1) الشكل (UI) صار مثل كلاود
- شريط جانبي (Sidebar) فيه لستة محادثاتك المحفوظة + زر "محادثة جديدة".
- خلفية كريمية دافية + خط Serif بالعنوان (Fraunces) + لون أساسي "طيني" (Clay/Terracotta) — نفس الهوية البصرية لموقع Claude.ai.
- فقاعات رسائل مدورة، المستخدم داكن على اليمين، والمساعد فاتح على الشمال.
- كل شي متجاوب (Responsive) ويشتغل على الموبايل.

### 2) تغيير اسم الموديل بحرية
- زر ⚙️ "الإعدادات والذاكرة" بأسفل الشريط الجانبي (أو تضغط على شارة اسم الموديل بأعلى الصفحة).
- بالحقل الأول تكتب أي اسم موديل متوفر عند Groq (مثلاً `llama-3.3-70b-versatile`، `openai/gpt-oss-120b`، أو أي موديل جديد يطلع عندهم).
- الاسم ينحفظ بالمتصفح وينرسل مباشرة لملف `api/chat.js`، اللي صار يقرأ اسم الموديل من الطلب نفسه بدل ما يكون مثبّت بالكود.
- **مهم:** إذا تريد المساعد يحلل صور تحتاج تختار موديل يدعم الصور (Vision) — مثل `meta-llama/llama-4-scout-17b-16e-instruct` (تأكد من الاسم الدقيق بصفحة Groq Console → Models لأنه ممكن يتغيّر).

### 3) الحفظ التلقائي (Persistence)
كل شي ينحفظ بـ `localStorage` بمتصفحك (مو على سيرفر خارجي، يعني خصوصيتك محفوظة 100% وما يشوفها أي أحد غيرك):
- **كل المحادثات** بكامل تفاصيلها (تكدر تفتح وحدة قديمة أو تحذفها من الشريط الجانبي).
- **اسم الموديل، اسم المساعد، وشخصيته**.
- **"الذاكرة الدائمة"**: حقل خاص بالإعدادات تكتب فيه معلومات عنك (اسمك، تفاصيل شخصية، طريقة الحچي اللي تريدها...) وتترسل تلقائيًا مع **كل** رسالة جديدة بأي محادثة، يعني المساعد "يتذكرها" دايمًا حتى لو سكرت المتصفح ورجعت بعد أيام.

> ملاحظة: الحفظ محلي بالمتصفح نفسه. إذا مسحت بيانات المتصفح (Clear browsing data) أو فتحت الموقع من جهاز ثاني، البيانات ما تنتقل تلقائيًا. إذا تريد لاحقًا حفظ سحابي (يظهر بكل الأجهزة) ممكن نضيف قاعدة بيانات مجانية مثل Supabase أو Vercel KV — گلّي وأسويها وياك.

### 4) رفع الملفات والصور
- زر 📎 بجانب صندوق الكتابة يفتح لك اختيار ملفات أو صور (تدعم اختيار أكثر من ملف بنفس الوقت).
- **الصور**: تنرسل للموديل مباشرة (بصيغة Base64) — تشتغل تحليلها فقط إذا الموديل المختار يدعم الصور.
- **الملفات النصية** (`.txt .md .js .py .json .csv .html .css`): محتواها ينقرأ وينضاف كسياق تلقائي مع رسالتك.
- تكدر تشوف الملفات المرفقة كـ "chips" فوگ صندوق الكتابة وتحذف أي وحدة قبل الإرسال.

⚠️ Vercel (بالخطة المجانية) عنده حد أقصى لحجم الطلب (~4.5MB). لا ترفع صور أو ملفات كبيرة جدًا وإلا الطلب يفشل.

### 5) "نكدر نكول ونسولف" — الاتصال الصوتي
هذا مبني بتقنية مجانية موجودة أصلاً بالمتصفح (Web Speech API)، بدون أي خدمة خارجية مدفوعة:
- 🎤 **مايك**: اضغط عليه، احچي عربي (عراقي)، وتلقائيًا يتحول كلامك لنص بصندوق الكتابة. اضغط عليه مرة ثانية توقفه.
- 🔊 **قراءة صوتية**: زر بأعلى يمين الصفحة، إذا فعّلته المساعد يقرأ ردوده بصوت عالي تلقائيًا.
- **متطلب مهم**: هذي الميزة تشتغل زين بمتصفح **Chrome** (على الكمبيوتر أو أندرويد). بعض المتصفحات الثانية دعمها للعربي أضعف أو غير موجود، وبهاي الحالة يطلعلك تنبيه واضح.
- هذا "تحدث صوتي" وليس مكالمة فيديو/صوت حية بين شخصين — إذا قصدك شي مختلف (مثل مكالمة جماعية أو اتصال بين مستخدمين اثنين) گلّي أوضح لك الفرق ونشوف الحل المناسب (يحتاج تقنية إضافية مثل WebRTC وسيرفر signaling).

## كيف تشغّله؟ (نفس الخطوات القديمة بدون تغيير)

```bash
npm install -g vercel
cp .env.example .env
```
حط مفتاحك بملف `.env`:
```
GROQ_API_KEY=gsk_مفتاحك_هنا
```
ثم:
```bash
vercel dev
```

## كيف تنشره؟
نفس خطوات النشر القديمة بالضبط (GitHub → Vercel → إضافة `GROQ_API_KEY` بالـ Environment Variables → Deploy). ما تغيّر شي بهاي الخطوة.

## أفكار توسعة لاحقة (إذا تريدها)
- حفظ سحابي (Supabase / Vercel KV) حتى تشوف محادثاتك من أي جهاز.
- تسجيل دخول للمستخدمين (كل واحد عنده حسابه الخاص).
- اتصال صوتي/فيديو حقيقي بين شخصين (WebRTC).
- زر "توليد صورة" منفصل عبر خدمة صور مجانية.

گلّي أي وحدة من هاي تريدها وأبنيها وياك خطوة بخطوة.
